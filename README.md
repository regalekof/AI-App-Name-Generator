🌟 AI App Name Generator

Generate creative, unique, and brand-worthy app names using AI!
Fast, modern UI + Google Gemini & OpenAI support.

🆓 Get Your FREE API Key (No Credit Card Required)
✅ Option 1: Google Gemini (Recommended — 100% FREE)

Go to Google AI Studio → https://aistudio.google.com/

Sign in

Click “Get API Key”

Create or select an existing key

Copy your API key

🔧 Setup

Create a file named .env.local in the project root:

GEMINI_API_KEY=your_gemini_api_key_here


Restart your dev server — done!

⚡ Option 2: OpenAI (Optional — Requires $5 free credit)

Go to https://platform.openai.com/

Create an account

Generate an API key

Add it to .env.local:

OPENAI_API_KEY=your_openai_api_key_here

🚀 Run the Project Locally
# Install dependencies
pnpm install

# Start development server
pnpm dev


Then visit http://localhost:3000

✨ Features

🤖 AI-powered name generation (8–10 names per request)

📋 One-click copy to clipboard

🔄 Generate more with a single button

🎨 Clean, modern UI

🚀 Instant results

💯 Works offline using a built-in fallback name generator

🔌 Supports both Google Gemini & OpenAI

📝 Notes

If you don’t provide an API key, the app automatically uses a smart fallback generator that still produces high-quality names based on your theme.
